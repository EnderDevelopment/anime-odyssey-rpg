# Roblox RPG Game

This project is a comprehensive Roblox RPG game that includes various systems such as character creation, leveling, anime abilities, martial arts, fighting styles, anime equipment, guilds, missions, guild missions, dungeons, anime events, roulette, Robux bonus, inventory, status, in-game bonus, rarity equipment, anime bosses, PvP, enemy NPCs, anime war events, and animations. It is designed to provide a rich and immersive gaming experience for players.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Import the scripts into your Roblox Studio project.
4. Place the scripts in the appropriate locations in the game hierarchy.

## Use

1. **Character Creation**: Use the `CharacterCreation.lua` script to create new characters with customizable attributes.
2. **Level System**: Utilize the `LevelSystem.lua` script to manage character levels and experience points.
3. **Anime Abilities**: Add anime abilities to characters using the `AnimeAbilities.lua` script.
4. **Martial Arts**: Implement martial arts for characters with the `MartialArts.lua` script.
5. **Fighting Styles**: Define different fighting styles for characters using the `FightingStyles.lua` script.
6. **Anime Equipment**: Equip characters with anime equipment using the `AnimeEquipment.lua` script.
7. **Guilds**: Create and manage guilds with the `Guilds.lua` script.
8. **Missions**: Set up missions for players to complete using the `Missions.lua` script.
9. **Guild Missions**: Create missions specific to guilds with the `GuildMissions.lua` script.
10. **Dungeons**: Design and manage dungeons using the `Dungeons.lua` script.
11. **Anime Events**: Organize anime events with the `AnimeEvents.lua` script.
12. **Roulette System**: Implement a roulette system for players to spin and win rewards using the `RouletteSystem.lua` script.
13. **Robux Bonus**: Apply Robux bonuses to players using the `RobuxBonus.lua` script.
14. **Inventory System**: Manage player inventories with the `InventorySystem.lua` script.
15. **Status System**: Update character status manually or automatically using the `StatusSystem.lua` script.
16. **In-Game Bonus**: Apply in-game bonuses to players using the `InGameBonus.lua` script.
17. **Rarity Equipment**: Add rarity levels to equipment using the `RarityEquipment.lua` script.
18. **Anime Bosses**: Create anime bosses with unique abilities using the `AnimeBosses.lua` script.
19. **PvP System**: Handle player versus player interactions using the `PvPSystem.lua` script.
20. **Enemy NPCs**: Create and manage enemy NPCs using the `EnemyNPCs.lua` script.
21. **Anime War Events**: Organize anime war events with the `AnimeWarEvents.lua` script.
22. **Animations**: Add animations to characters and objects using the `Animations.lua` script.
